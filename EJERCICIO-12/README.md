Aprendí a consolidar un recorrido Full Stack completo reutilizando múltiples conceptos arquitectónicos en una sola aplicación, comprendiendo cómo combinar consultas de colecciones (GET), peticiones parametrizadas por ID (GET /:id), y modificaciones parciales de recursos (PATCH) de manera sincronizada con el estado de la interfaz móvil.
Modifiqué el archivo backend/src/main.ts para abrir la conectividad de red, estructuré los métodos de lectura y escritura temporal en criaturas.service.ts, expuse los endpoints correspondientes en criaturas.controller.ts, y actualicé frontend/App.tsx para combinar una lista horizontal navegable (FlatList + Pressable) con una tarjeta de detalles interactiva.
Obtuve una aplicación móvil robusta y plenamente integrada con el backend que permite listar criaturas, consultar los detalles específicos de cada una al seleccionarlas y actualizar sus métricas de forma persistente temporalmente en memoria con reflejo inmediato en la interfaz visual.
