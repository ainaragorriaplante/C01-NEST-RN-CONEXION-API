Aprendí a construir peticiones HTTP dinámicas basadas en parámetros de ruta (Path Params), comprendiendo cómo capturar un identificador introducido por el usuario en la interfaz móvil, enviarlo a través de una URL parametrizada hacia el backend de NestJS mediante fetch, y procesarlo utilizando el decorador @Param('id') para recuperar y retornar los datos específicos del elemento solicitado.
Modifiqué el archivo backend/src/main.ts para habilitar CORS y permitir que el servidor escuche en todas las redes, configuré el servicio heroes.service.ts para filtrar elementos del array según su ID, actualicé el controlador en heroes.controller.ts para exponer la ruta GET dinámica /heroes/:id, y diseñé la interfaz en frontend/App.tsx añadiendo un campo de entrada (TextInput), un botón de búsqueda y una tarjeta interactiva para renderizar los detalles del superhéroe obtenido.
Obtuve un flujo full-stack interactivo y totalmente funcional donde el usuario puede introducir un ID en la aplicación móvil, disparar una petición asíncrona precisa hacia el servidor local y visualizar de forma dinámica la ficha informativa del superhéroe correspondiente en la pantalla del dispositivo.
