Aprendí a integrar un backend de NestJS con un frontend en React Native utilizando el componente FlatList para renderizar colecciones de datos en forma de listas dinámicas, comprendiendo cómo estructurar servicios y controladores que devuelven arrays y cómo consumirlos de manera asíncrona mediante fetch, useState y el hook useEffect.
Modifiqué el archivo backend/src/main.ts habilitando CORS y configurando el servidor para escuchar en todas las interfaces de red, creé el servicio productos.service.ts para gestionar un array de productos con un cuarto elemento añadido, configuré el controlador en productos.controller.ts para exponer la ruta GET correspondiente, y actualicé frontend/App.tsx para cargar y representar dichos elementos mediante tarjetas visuales.
Obtuve un flujo full-stack completamente operativo en el que la aplicación móvil se comunica con el servidor local sin errores de red, permitiendo que la interfaz procese la respuesta JSON y despliegue dinámicamente cada producto en una lista estructurada y eficiente con FlatList.
