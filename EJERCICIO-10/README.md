Aprendí a implementar operaciones de escritura y modificación de datos desde una aplicación móvil utilizando el método HTTP PATCH, comprendiendo cómo enviar opciones de configuración en las peticiones asíncronas con fetch y cómo gestionar la persistencia temporal en memoria a través de servicios y controladores en NestJS.
Modifiqué el archivo backend/src/main.ts para habilitar el acceso de red, estructuré la lógica de actualización en mascotas.service.ts, expuse el endpoint @Patch(':id/like') en el controlador mascotas.controller.ts, y actualicé la interfaz en frontend/App.tsx añadiendo un botón interactivo configurado con el método de modificación y la actualización del estado visual.
Obtuve un flujo full-stack de escritura interactivo en el que la acción de pulsar el botón en la aplicación móvil envía una solicitud de cambio al servidor local, modificando de manera dinámica el recurso en memoria y reflejando inmediatamente el nuevo conteo de likes en la interfaz del usuario.
