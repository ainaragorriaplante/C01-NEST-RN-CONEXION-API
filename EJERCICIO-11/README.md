Aprendí a enviar objetos nuevos desde una aplicación móvil hacia el servidor utilizando el método HTTP POST, comprendiendo cómo estructurar las cabeceras (Content-Type: application/json) junto con JSON.stringify en las peticiones asíncronas de fetch, y cómo capturar dichos datos en el backend mediante el decorador @Body() de NestJS.
Modifiqué el archivo backend/src/main.ts para habilitar el acceso de red, añadí la lógica de almacenamiento temporal en productos.service.ts, expuse el endpoint @Post() en el controlador productos.controller.ts, y actualicé la interfaz en frontend/App.tsx implementando campos de entrada (TextInput) y un botón para registrar nuevos elementos que actualizan de forma automática la lista visualizada.
Obtuve un flujo full-stack completo de creación de recursos donde la introducción de datos en el frontend móvil genera una solicitud HTTP tipo POST procesada correctamente por el servidor, permitiendo ampliar el array en memoria y reflejar instantáneamente el nuevo producto en la interfaz.
