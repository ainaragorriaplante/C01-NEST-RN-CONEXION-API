Aprendí a integrar un backend desarrollado en NestJS con un frontend en React Native mediante peticiones HTTP asíncronas, comprendiendo la importancia de habilitar el intercambio de recursos de origen cruzado (CORS) y de configurar correctamente las direcciones IP locales para la comunicación entre dispositivos o emuladores.
Modifiqué el archivo main.ts de NestJS para habilitar CORS mediante app.enableCors(), configuré el controlador en mensaje.controller.ts para que devuelva un objeto con el mensaje de conexión, y diseñé la interfaz en el archivo index.tsx de React Native utilizando componentes visuales (SafeAreaView, Text y Button) junto con una función asíncrona basada en fetch para consumir la API.
Obtuve un flujo de conexión completo y funcional entre el cliente móvil y el servidor local, permitiendo que la interfaz renderice los elementos visuales correctamente y que, al presionar el botón, la aplicación consulte la ruta del backend y procese la respuesta recibida.
